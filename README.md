# Right First Vial: Real-Time, GPU-Accelerated Prediction and Explanation of Color Carryover

**Team:** Monank Gajjar's team (Monank Gajjar, Malhar, Shubham, Ajay)
**Challenge:** Dataset 2: Fluid Mixing Station 3

## Our project

At Station 3, leftover liquid from the previous recipe in the shared mixing path discolors the first vial after a recipe change (e.g. blue after orange comes out green). The current check only compares a vial's color with a database of known colors, so it can't tell whether the vial matches its intended recipe.

We're building a real-time system that:
1. **Warns** before a risky recipe change.
2. **Detects** color and fill problems from the `vial_fill` camera, using a GPU segmentation model trained on digital-twin images.
3. **Explains** the likely cause to the operator.

A simple CPU pipeline serves as the baseline.

- **Team brief:** [`docs/Dataset2_Fluid_Mixing.docx`](docs/Dataset2_Fluid_Mixing.docx)
- **Code by stage:** `explore/` → `preprocess/` → `features/` → `model/`
